# Contributing Workflows

Check the official
[ComfyUI-LTXVideo](https://github.com/Lightricks/ComfyUI-LTXVideo) repository
before submitting. If the workflow is generally useful and canonical, propose
it upstream first.

Submissions here require a complete manifest, portable JSON, instructions,
preview provenance, and a dated test record. Promotional links, embedded
credentials, undocumented custom nodes, and unlicensed assets are rejected.
